# TabBar 图标说明

## 需要准备的图标文件

小程序 TabBar 需要以下图标文件（建议尺寸：81px × 81px，PNG 格式）：

| 文件名 | 说明 | 状态 |
|--------|------|------|
| home.png | 首页图标（未选中） | 灰色 |
| home-active.png | 首页图标（选中） | 蓝色 #1890ff |
| order.png | 工单图标（未选中） | 灰色 |
| order-active.png | 工单图标（选中） | 蓝色 #1890ff |

## 图标获取方式

### 方式一：使用 iconfont（推荐）
1. 访问 [iconfont.cn](https://www.iconfont.cn/)
2. 搜索 "首页" 或 "home"
3. 搜索 "工单" 或 "order" / "list"
4. 下载为 PNG 格式，颜色分别设置为 #999999 和 #1890ff

### 方式二：使用微信官方图标库
1. 微信开发者工具 → 详情 → 本地设置
2. 勾选"使用本地图片资源"
3. 使用 WeUI 提供的图标

### 方式三：临时方案（开发阶段）
可以暂时注释掉 app.json 中的 tabBar 配置，使用页面内导航代替。

## 图标设计建议

- 尺寸：81px × 81px
- 格式：PNG（支持透明背景）
- 未选中颜色：#999999
- 选中颜色：#1890ff
- 风格：线性图标或面性图标，保持一致
